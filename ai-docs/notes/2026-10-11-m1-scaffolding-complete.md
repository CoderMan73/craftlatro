# M1 Complete: Scaffolding and dependency integration

## Problem
The craftlatro project had no build system, source files, or dependencies. Need to scaffold
a Fabric 1.26.2 mod project with Loom, add Rinku as a dependency, and verify the API surface
supports a flat GUI browser screen.

## Solution
1. Generated the Fabric project using `npx @fabricmc/cli init` with `-y` flag, then adapted
   the template for the `craftlatro` mod ID and Minecraft 26.2.
2. Fabric Loom version: 1.18.4 (resolved from `loom_version=1.18-SNAPSHOT` in gradle.properties)
3. Fabric API version: 0.161.0+26.2 (from `https://fabricmc.net/develop` recommendations)
4. Fabric Loader version: 0.19.5 (recommended for MC 26.2)
5. Java: 25 (required by Loom for MC 26.2)
6. Rinku version: 3.0.4-26.2 from `https://keksuccino.github.io/maven/`

### Version mismatch note
PLAN.md (AGENTS.md) referenced Rinku as `de.keksuccino:rinku-fabric:3.0.4-1.26.2`, but the
actual published Maven artifact uses `3.0.4-26.2` (Minecraft version `26.2`, not `1.26.2`).
This was confirmed by browsing the Rinku GitHub Pages Maven repository at
`https://github.com/Keeksuccino/keksuccino.github.io` and checking the `publish_to_maven.py`
script which constructs the version as `{mod_version}-{minecraft_version}`.

### Gradle wrapper
Used the wrapper generated by the Fabric CLI (Gradle 9.7.1). The `genIntellij` task from
AGENTS.md key commands is not available in Loom 1.18.4; the equivalent task is `ideaSyncTask`
(auto-triggered on IDE import). `runClient` is the task to launch a dev client.

## Rinku API Verification

### Public API confirmed
`Rinku.java` (de.keksuccino.rinku.Rinku) provides:
- `Rinku.createBrowser(String url, boolean transparent)` — creates a `RinkuBrowser`
- `Rinku.isInitialized()` — check if CEF is initialized
- `Rinku.getClient()` — access the CEF client wrapper
- `Rinku.getSettings()` — access/modify Rinku settings

`RinkuBrowser.java` (de.keksuccino.rinku.RinkuBrowser, extends CefBrowserOsr) provides:
- `getTextureIdentifier()` — returns texture Identifier for `GuiGraphics.blit()`
- `isTextureReady()` — check if texture is ready
- `resize(int width, int height)` — resize browser
- `loadURL(String url)` — navigate
- `goBack()`, `goForward()`, `reload()` — navigation
- `sendMousePress(int x, int y, int button)` — mouse press (note: MC swaps button 1/2)
- `sendMouseRelease(int x, int y, int button)` — mouse release
- `sendMouseMove(int x, int y)` — mouse move
- `sendMouseWheel(int x, int y, double amount, int modifiers)` — mouse wheel
- `sendKeyPress(int keyCode, long scanCode, int modifiers)` — key press
- `sendKeyRelease(int keyCode, long scanCode, int modifiers)` — key release
- `sendKeyTyped(char c, int modifiers)` — character input (no modifier info available)
- `close()` — close browser
- `setFocus(boolean)` — set focus
- `useBrowserControls(boolean)` — enable/disable built-in shortcuts

### Example screen reference
Rinku includes `de.keksuccino.rinku.example.ExampleScreen` which is a perfect reference
implementation of a flat GUI browser screen. It:
1. Extends `net.minecraft.client.gui.screens.Screen`
2. Creates browser via `Rinku.createBrowser(url, transparent)` in `init()`
3. Renders texture via `extractRenderState(GuiGraphicsExtractor, ...)` using `blit()`
4. Maps mouse/keyboard events to the browser
5. Closes browser on `onClose()`

### MC 26.2 API changes
MC 26.2 introduced new event-based input methods on Screen:
- `extractRenderState(GuiGraphicsExtractor, int, int, float)` replaces `render(GuiGraphics, ...)`
- `mouseClicked(MouseButtonEvent, boolean)` replaces `mouseClicked(double, double, int)`
- `mouseReleased(MouseButtonEvent)` replaces `mouseReleased(double, double, int)`
- `keyPressed(KeyEvent)` replaces `keyPressed(double, double, int, int, int)`
- `keyReleased(KeyEvent)` replaces `keyReleased(double, double, int, int, int)`
- `charTyped(CharacterEvent)` replaces `charTyped(int, int)`
- `MouseButtonEvent` has `x()`, `y()`, `button()`, `modifiers()`
- `KeyEvent` has `key()`, `scancode()`, `modifiers()`
- `CharacterEvent` has only `codepoint()` (no modifiers)
